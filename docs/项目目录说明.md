# 项目目录说明
- frontend/  Vue3 前端：src/views 十个页面、src/api 接口封装、src/stores 状态、src/router 路由、src/layout 布局
- backend/   FastAPI 后端：app/api 路由、app/services 业务、app/models ORM、app/core 配置与安全、
             app/tasks Celery 任务、app/datasources 数据源适配器（一个游戏一个文件）、ml/ 算法模型
- sql/       建表与视图脚本（阶段 2 起填充 30 张表）
- data/      模拟与样本数据（raw 原始 / processed 处理后）
- docs/      设计文档与论文配图
